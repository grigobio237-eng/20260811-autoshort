# Shorts Automation Generator

이 프로젝트는 n8n 웹훅과 연동하여 AI 쇼츠 영상을 자동 생성하는 대시보드입니다. 
Vanilla HTML과 Tailwind CSS (CDN)를 사용하여 구성되었습니다.

## 주요 기능
- **쇼츠 주제 입력**: 사용자가 원하는 쇼츠 주제를 입력할 수 있습니다.
- **실시간 상태 표시**: n8n 워크플로우로 요청이 전송되면 진행 상태(대본 작성, 이미지 생성 등)를 표시합니다.
- **결과 확인**: n8n 웹훅에서 응답이 오면 비디오 플레이어 또는 생성된 스크립트 내용을 보여줍니다.

## 실행 방법
별도의 빌드 과정 없이 `index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 주의 사항
- n8n 웹훅 URL은 테스트용 Tunnel URL로 설정되어 있으므로 필요에 따라 코드 내 `WEBHOOK_URL` 변수를 수정하세요.
